# 운영 앱 검증 (0.3.0)

## 로컬 검증: 2026-10-11

- Windows / Python 3.14: 최종 전체 Python unittest **102개 통과**. 기존 70개 + 운영/SDK 32개.
- Node.js 보고서 데이터 테스트: **8개 통과**.
- Chromium 기존 보고서 비교: 예제, 검색, 타임존, 4개 탭, 구버전 입력, 잘못된 JSON, HTML 이스케이프, 내보내기, 복원, 데스크톱/모바일 통과.
- Chromium 운영 앱: 초기 조직 생성 → 로그인 → 소스/키 생성 → 합성 이벤트 수집 → 사건 생성 → 담당자/상태 변경 → 조사 메모 → JSON 내보내기 통과.
- 별도 샘플 앱: 계정 생성 → 실제 로그인 실패 5회 → 성공 1회 → SDK 영속 큐 전송 → 운영 앱 사건 생성 통과.
- 운영 서버 프로세스를 종료·재시작한 뒤 로그인 세션·이벤트 12개·사건 4개 유지 확인.
- 조회자 로그인 후 관리자 메뉴와 수정 기능 미노출 확인. API 테스트에서는 권한 위반을 서버가 거부하는 것도 확인.
- 1440px 데스크톱, 390px/360px 모바일에서 페이지 전체 가로 넘침 없음. 데이터 표는 내부 가로 스크롤 사용. 화면 스크린샷 직접 확인.
- 조직 간 상세 조회·사건 수정·메모·사용자 변경·소스 폐기·예외·담당자 지정·알림 재시도 차단 검사.
- 비밀번호/수집 키 평문 미저장, 검증 오류의 비밀 미반환, HTTPS Secure/HttpOnly/SameSite 쿠키, 로그인 속도 제한 검사.
- 재전송 중복 방지, 같은 ID/다른 내용의 원자적 취소, 순서 뒤바뀜·배치 분할·사건 근거 확장 검사.
- 백업 복사본 이벤트와 무결성, 보관 정리의 연관 메모/알림 삭제, 미설정 외부 알림 건너뛰기, 재시도 시 비밀 오류 문자열 미저장 검사.
- 과거/미래 시각 로그를 수집 큐에서 제외하고 통계를 남겨 정상 이벤트 배치를 막지 않는 회귀 테스트 통과.
- wheel 빌드와 74개 패키지 파일 확인. 설치본으로 운영 화면·API·스키마·기존 비교 자산 제공 확인. Windows 실행기 구문 검사 통과.

실제 사용자 계정·수집 키·로그·DB는 저장소에 포함하지 않습니다. 테스트는 임시 데이터와 합성 주소를 사용하며 키를 출력하지 않습니다.

## 아직 외부에서 확인해야 하는 것

- 실제 SMTP/HTTPS 웹훅 수신: 설정이 비어 있어 외부 전송은 미검증. 화면 알림과 큐·재시도 로직은 검증됨.
- 회사 서버·도메인·TLS 프록시·방화벽·OS 권한: 해당 환경을 제공받지 않아 배포 검증은 미실행.
- 대규모 부하·고가용성·독립 침투 테스트·보안/규제 인증: 수행하지 않음.
