# Little Parcel Co. — 맵 확장과 연료 업데이트

2026-10-02. 실행 파일은 루트의 `index.html` 하나입니다. 개발 파일·패키지·서버는 게임 배포에 포함하지 않아도 됩니다.

## 새 지역과 주행

- 섬의 지면 면적을 기존 대비 약 2.4배로 확장했습니다. 기존 마을을 유지하면서 동쪽 공원과 북쪽 언덕 주택가를 연결했습니다.
- 배달 가능한 주택 6채를 추가했습니다: 사과나무집, 라벤더집, 해돋이 전망집, 별빛 다락집, 솔방울 오두막, 목장 옆 노란집. 각 집에는 충돌 경계·진입 도로·정차 구역·실제 주문이 있습니다.
- 솔바람 산책 공원에는 주민 5명이 전용 산책로를 왕복합니다. 벤치·분수·나무·입구와 도로 옆 배달 정차 구역을 따로 배치했습니다. 주민은 차도나 정차 차량 앞으로 갑자기 이동하지 않습니다. 공원 안으로 운전해 주민과 충돌하면 게임 오버가 됩니다.
- 주도로 8 m, 확장 도로 9 m, 연결 도로 최소 6.5 m, 돌다리 8.8 m로 넓혔습니다. 주택 진출로의 가로등은 현관 옆으로, 해안 바위와 배는 확장된 해안에 맞춰 옮겼습니다.
- 솔바람 언덕 정상은 높이 12 m입니다. 차체 높이·기울기·카메라·도로·길 안내·정차 구역이 같은 지형을 사용합니다. 도로와 안내선은 지형 삼각형에 맞춰 분할하여 오르막에서 땅에 묻히는 틈을 제거했습니다.
- 오르막에서는 가속과 최고 속도가 줄어들고, 거리당 연료 소비가 증가합니다. 기본 엔진으로도 모든 배달 도로를 올라갈 수 있습니다. 후진과 내리막도 실제 이동 방향의 경사를 사용합니다.

## 연료와 게임 오버

- 새 출발 시 60 L. 평지 기본 소비량은 1 m당 0.04 L이며 오르막은 더 많이 소비합니다. 정차·지도·메뉴·일시정지에서는 소비하지 않습니다.
- 상단 연료계, 15 L 이하 경고, 5 L 이하 위험 색상, 주유소 길 안내 버튼을 추가했습니다.
- 주요 주문 3개로 돌다리를 수리하면 강 건너 정상 주유소가 열립니다. 주유 정차 원에서 완전히 멈춘 뒤 **E**, 또는 터치 운전판의 **차고 / 주유** 버튼을 누르세요.
- 가격은 1 L당 2 동전. 5 L·10 L·가득 충전 중 선택합니다. 남은 탱크 용량만큼만 충전하며 정수 동전으로 올림 결제합니다. 결제 금액은 구매 전에 표시됩니다. 동전 부족·정차 구역 밖·중복 만충 구매는 거부합니다.
- 연료가 0이 되거나 주민과 충돌하면 즉시 게임 오버입니다. 운전·배달·시간 진행과 Esc 우회를 차단합니다.
- 게임 오버 순간 동전, 주요/일반 미션 기록, 적재/수락 물품, 배달 내역, 날짜와 해금 상태를 초기화합니다. 재출발하면 우체국에서 1장 첫 미션·0동전·빈 적재·연료 60 L로 시작합니다.
- 요청한 미션·돈 초기화와 별개로 **구매한 차량 업그레이드와 음량·그래픽·카메라 설정은 유지**합니다. 타이틀의 '처음부터'는 기존처럼 전체 저장을 초기화합니다.
- 게임 오버 초기화 상태를 자동 저장과 백업 모두에 기록합니다. 새로고침이나 백업 복구로 직전 미션·돈이 부활하지 않습니다.

## 주문과 저장

- 일반 주문에 새 주택과 공원을 포함한 30종 이상의 수령/배달 조합을 구성했습니다. 매 게임 날짜마다 주문 구성이 바뀌며, 수락·적재 중인 물품은 다음 날에도 유지합니다.
- 언덕 해금 뒤에는 일반 주문에도 원거리 목적지가 편성됩니다. 먼 배달은 추가 동전을 지급합니다. 주요 미션에도 전망집·사과나무집·솔방울 오두막·별빛 다락집을 연결했습니다.
- 일반 배달 완료 건수와 최근 50건의 배달 내역을 저장합니다. 메뉴에서 내역을 볼 수 있습니다.
- 이전 저장을 불러오면 진행과 차량 구매를 유지하고 연료 필드는 60 L로 보완합니다. 손상된 연료 값·물품·위치도 검증합니다. 언덕의 저장 위치는 지형 높이에 맞춰 복원합니다.

## 검증

- Windows Chrome 자동 검사 **70/70 통과**, 브라우저 오류 로그 0건.
- 주요 미션 15개, 도중 정상 주유소 방문과 유료 주유, 추가 주택 6채와 새 공원의 수령/배달을 연속 가속·조향·후진·제동으로 완료했습니다. 이 연속 검사에는 중간 순간이동이나 차량 구조를 사용하지 않았습니다. 주민 움직임·충돌·연료 소모·오르막 효과가 켜져 있습니다.
- 주유비 부족, 부분 충전, 탱크 상한, 연료 저장/복원, 게임 오버 잠금, 돈/미션/백업 초기화, 공원 보행 동선과 도로 표면을 별도로 검사했습니다.
- 화면용 검증 위치 배치와 주행 검사를 구분했습니다. 화면 검증 모드는 장면 확인용이며 실제 운전 완주의 근거는 연속 주행 검사입니다.
- 390×844 작은 화면과 데스크톱에서 연료계·주유 화면·조작 버튼·주문 패널을 확인했습니다. 실제 휴대폰 성능 검사는 아닙니다.
- 일반 사용자 저장과 자동/화면 QA 저장은 별도 키를 사용합니다. 실제 사용자에게 게임 오버를 발생시키거나 기존 진행을 초기화하는 검사는 하지 않았습니다.

자동 주행은 실제 신규 플레이어의 사용성 검사를 대신하지 않습니다. 다른 브라우저·실제 휴대폰·저사양 GPU·장시간 플레이는 별도 검증이 필요합니다. 직접 `file://` 실행과 파일 선택 가져오기는 검증 도구의 권한 제한 때문에 끝까지 자동 확인하지 못했습니다. 공개 업로드/배포도 수행하지 않았습니다.

## 재검증

원본 `parcel/game.html`을 수정한 후 `node parcel/build.mjs`로 `index.html`을 생성합니다. 실행용 HTML에는 Three.js와 라이선스가 포함되어 외부 그래픽 라이브러리·폰트 요청이 없습니다.

- `?check=release`: 전체 자동 검사. `littleParcelTest` 저장 사용.
- `?check=play`: 수동 플레이 QA. `littleParcelPreview` 저장 사용.
- `?check=expansion`: 새 지역·주유소·연료 고갈 화면 확인용 위치 배치. `littleParcelExpansionPreview` 저장 사용. 일반 플레이에는 사용하지 마세요.
- 일반 플레이: 쿼리 없는 `index.html`.

화면 증빙은 `parcel/expanded-park.jpg`, `parcel/expanded-hill.jpg`, `parcel/fuel-station.jpg`, `parcel/fuel-game-over.jpg`입니다. 검사 결과는 `parcel/expansion-checks.json`에 기록했습니다. 확장 전 검증 이력은 `RELEASE-NOTES.md`에 남겨 두었습니다.
