# Little Parcel Co. 이전 출시 후보 검증

이 문서는 맵 확장 전 버전의 검증 이력입니다. **현재 버전의 기능·게임 오버 규칙·검증 결과는 [EXPANSION-NOTES.md](EXPANSION-NOTES.md)를 참고하세요.** 현재는 주민 충돌 또는 연료 고갈 시 미션 기록·돈·물품을 초기화하므로 아래의 이전 '진행 유지' 규칙은 더 이상 적용되지 않습니다.

검증일: 2026-10-02. 배포 대상은 루트의 `index.html` 하나입니다. 개발용 `parcel/`와 `.parcel-build/`는 배포할 필요가 없습니다.

## 수정 사항

- 운전 규칙 변경: 일반 차량의 플레이어 근접 회피·갓길 이동·근접 정지를 제거했습니다. 플레이어 위치와 무관하게 같은 차선을 따라 주행합니다.
- 주민 충돌: 차체 방향을 반영한 충돌 검사와 이동/회전 중간 지점 검사를 적용했습니다. 주민과 접촉하면 즉시 게임 오버로 전환하고 운전·배달·시간을 정지합니다. Esc나 일시정지 메뉴로 우회할 수 없습니다.
- 재출발: 게임 오버 화면에서 우체국 앞 재출발 또는 타이틀 복귀를 선택할 수 있습니다. 동전·물품·주요 배달은 유지하고, 자동 저장에는 충돌 위치 대신 안전한 출발 위치를 기록해 재실행 직후 같은 충돌이 반복되지 않게 했습니다. 첫 안내와 조작 도움말에도 새 규칙을 명시했습니다.
- 화면 보완: 우체국 앞 빈 공간에 보행로·벤치·안내판과 4개의 낮은 정원을 구성했습니다. 정원은 도로에서 반경+5 m, 배달 구역에서 반경+6 m 이상 떨어져 있으며 기존 나무와 겹친 위치는 옮겼습니다.
- 건물 보완: 빵집은 진열창·외벽 가로 장식, 꽃집은 낮은 지붕·온실 프레임, 카페는 별도의 사각 경사지붕, 서점은 높은 지붕·세로 외벽 장식, 우체국은 시계탑·원형 창, 주택은 창가 화분·현관을 적용했습니다. 출입문에 겹치는 외벽 장식도 제거했습니다.
- 안내 보완: 가는 점선 대신 0.56 m 경로와 0.86 m 흰 테두리, 약 5 m 간격 방향 화살표를 적용했습니다. 정차 원은 평면 도색과 흰 테두리로 구성하고 수령/배달 라벨 및 파랑/초록 색상으로 구분합니다. 사용하지 않는 우체국 주차 원은 회색으로 표시합니다.
- Three.js와 후처리를 HTML 내부에 포함하고 외부 폰트·CDN 요청을 제거했습니다. 별도 설치나 실행용 빌드 없이 약 1 MB의 HTML로 실행합니다. Three.js MIT 라이선스도 포함했습니다.
- 건물 가림을 완화하는 카메라 상승·투명화와 방향·높이 보간을 적용했습니다.
- 도로 경로 안내, 실제 개울 곡선에 맞춘 충돌, 회전·후진으로 통과 가능한 연결 도로와 정차 구역을 정리했습니다. 일반 차량은 별도의 차선 주행을 사용합니다.
- 상점별 지붕·진열 장식, 차량 뒷유리·배지, 꽃의 줄기와 정원, 낮은 목적지 표지를 다듬었습니다.
- 15개 주요 주문의 물품과 다리 수리·시장 해금·등대 복구·축제 사건을 직접 연결했습니다.
- 저장 실패를 지속 안내하고 이전 자동 저장 백업을 유지합니다. 차량 위치·방향·시점·설정·물품을 복원하며 잘못된 저장 값과 중복 주문을 정리합니다.
- 저장 JSON 내려받기/불러오기와 차량 구조 메뉴를 추가했습니다. 저장 문자열을 HTML로 실행하지 않습니다.
- 첫 배달 안내, 접을 수 있는 주문 패널, 지도·시점·메뉴 버튼, 터치 운전 버튼, 작은 화면 배치, 키보드 설정 조작을 개선했습니다.
- 창 전환 시 운전을 정지하고 숨겨진 창의 렌더링을 줄였습니다. 낮은 그래픽에서 꽃·줄기·비·후처리 부담을 함께 줄입니다. WebGL 오류에는 재실행 안내를 표시합니다.

## 확인한 범위

- Windows Chrome에서 자동 검사 52/52 통과. 정원·외형·안내 검사에 더해 차량 근접 반응 제거, 전진/후진/회전/빠른 주민 통과 충돌, 근접 비접촉 통과, 게임 오버 고정, 안전 저장, 재출발 진행 유지 검사를 포함했습니다. 브라우저 오류 로그는 0건입니다.
- 주요 주문 15개를 하나의 연속 주행으로 완료했습니다. 게임의 가속·조향·후진·제동 및 충돌 판정을 사용했으며, 수령/배달 간 위치 순간이동이나 구조 기능을 사용하지 않았습니다. 약 2,101 m, 게임 내 모의 주행 시간 23.2분입니다. 이는 자동 운전 검사이며 실제 신규 사용자의 사용성 검사를 대신하지 않습니다.
- 주민의 움직임과 주민 충돌 판정을 활성화한 상태에서도 주요 주문 15개 연속 주행을 완료했습니다. 별도의 충돌 UI 검사에서 실제 가속 입력으로 주민에게 접근해 게임 오버를 발생시켰고, Esc 잠금 및 재출발 후 42 동전·물품 1개·주요 배달 진행 유지도 확인했습니다. 이 UI 검사는 분리된 테스트 저장을 사용했습니다.
- 주문 수락·정차 수령·배달·적재 한도·구매·5개 챕터·엔딩·해금·날씨·카메라·도로 경로·충돌·저장 실패·저장 값 검증을 확인했습니다.
- 일반 사용자 저장과 별도 QA 저장을 분리했습니다. 기존 사용자 진행(주요 배달 2/15, 적재 1/8)을 초기화하지 않고 유지했습니다.
- 메뉴에서 JSON 저장 파일이 실제로 다운로드되어 위치·방향·시점·주문·설정이 포함된 것을 확인했습니다. 페이지 다시 열기 시 주문과 음량도 복원됐습니다.
- 390×844 화면에서 터치 버튼과 주문 패널을 확인했습니다. 자동으로 접힌 주문은 필요할 때 펼칠 수 있고 길 안내와 겹치지 않습니다. 이 검사는 화면 크기 검사이며 실제 휴대폰 성능 검사가 아닙니다.
- 실행 중 외부 그래픽 라이브러리·폰트 요청이 없는 것을 검사했습니다.

## 출시 전에 별도 확인할 범위

- 직접 `file://` 실행과 저장 파일 선택을 통한 가져오기는 검증 브라우저/확장 권한 제한으로 끝까지 자동 확인하지 못했습니다. 보안 설정을 낮추거나 우회하지 않았습니다. 저장 데이터 정규화·재적용은 자동 검사로 확인했습니다.
- 다른 브라우저, 실제 휴대폰, 저사양 GPU, 장시간 플레이, 신규 사용자의 길 찾기/조작 사용성은 별도 검증이 필요합니다. 모든 환경에서 무결함이라고 보증하지 않습니다.
- 지원 환경은 WebGL2와 최신 JavaScript를 지원하는 현대 브라우저입니다. 브라우저 자동 저장은 브라우저·사이트 주소별이며, 시크릿 모드나 저장소 차단/삭제 시 유지되지 않을 수 있습니다. 다른 환경으로 옮길 때 메뉴에서 JSON을 백업하세요.
- 공개 배포는 안정적인 동일 주소에서 제공하는 것을 권장합니다. 공개 업로드나 호스팅 배포는 수행하지 않았습니다.

## 개발 및 재검증

원본은 `parcel/game.html`, 배포 파일은 생성된 `index.html`입니다. 원본 수정 후 루트에서 `node parcel/build.mjs`를 실행하세요. 빌드에는 기존 개발 환경의 esbuild와 `.parcel-build/package`의 공식 Three.js 0.169.0 패키지가 사용됩니다. 배포 파일 실행에는 이 개발 의존성이 필요 없습니다.

로컬 HTTP 서버에서 `index.html?check=release`를 열면 전체 검사를 실행하고 화면에 JSON 결과를 표시합니다. 검사 데이터는 `littleParcelTest` 저장 키를 사용합니다. `?check=play`는 실제 사용자 저장을 건드리지 않는 수동 QA 모드입니다. 일반 플레이에는 쿼리 없는 `index.html`을 사용하세요.

화면 증빙: `parcel/game-over.jpg`(주민 충돌), `parcel/visual-update.jpg`(마을 시각 보완). 이전 버전 화면은 `parcel/release-preview.jpg`입니다.
